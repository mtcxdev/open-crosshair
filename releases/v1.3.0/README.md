## 🌟 What's New in v1.3.0

OpenCrosshair v1.3.0 introduces a ground-up redesign of the user interface, delivering a modern, high-precision desktop experience tailored for competitive esports and streaming.

### 🎨 1. Re-architected Modern UI/UX
* **Precision Workspace Layout**: Streamlined the multi-column studio with seamless hierarchy, responsive layout containers, and elimination of clutter.
* **Precision Controls**: Replaced clunky native inputs with custom, high-precision range sliders with active track fills, direct numeric steppers, and iOS/Linear-style pill toggles.
* **Segmented Navigation & Layers**: Integrated crisp segmented controls for quick layer switching (Arms, Dot, Ring, Chevron, Dynamics) with active indicator dots.
* **Enhanced Visual Clarity**: Fine-tuned dark theme tokens, improved contrast ratios, and optimized subpixel typography rendering on Windows.

### 🖥️ 2. Desktop Overlay Focus Coordination
* **Smart Studio Concealment**: Automatically hides the fullscreen desktop overlay reticle while OpenCrosshair Studio is focused, eliminating duplicate crosshairs across your editing canvas.
* **Instant In-Game Restoration**: Instantly restores the HUD reticle when you switch to your game, click onto the desktop, or minimize to the system tray.
